Project proposal

PAC Learning

Probably Approximately Correct learning

How can a learner use a finite amount of data to make reliable predictions on examples it has never seen?

Why I chose this topic

I encountered PAC learning in previous machine learning and reinforcement learning coursework, but did not explore it in depth because it was not the main focus. This project gives me an opportunity to build on that familiarity and develop a clearer understanding of the framework and its guarantees.

My topic remains the same as in my initial proposal. The plan below develops it into a sequence of website sections, with finite hypothesis classes as the main focus and VC dimension as a possible extension.

Proposed website outline

Planned sections, in order

  1. Introduction and motivation

    I will introduce the problem of generalization: why performing well on training data does not by itself explain performance on unseen data. I will explain what PAC learning aims to formalize and why guarantees about accuracy, confidence, and the amount of data are useful.

  2. The PAC learning framework

    I will define the instance space, target concept, hypothesis class, and true versus training error. I will explain the accuracy parameter ε and failure probability δ, along with the assumptions of independent, identically distributed samples from an unknown distribution and realizability for the main result.

  3. PAC learning with a finite hypothesis class

    I will state the finite-class PAC guarantee in the realizable setting for a learner that returns a hypothesis consistent with the training data. I will explain how the sufficient sample size depends on the size of the hypothesis class, the desired accuracy, and the desired confidence, and clarify the assumptions under which the guarantee holds.

  4. A step-by-step proof

    I will first bound the probability that a single hypothesis with true error greater than ε remains consistent with every training example. I will then use a union bound over the finite hypothesis class and rearrange the result to obtain a sufficient sample size, explaining the intuition behind each step.

  5. A worked example and sample complexity

    I will apply the theorem to threshold classifiers on a finite, ordered domain, where the hypothesis class can be listed explicitly. I will choose values for ε and δ, calculate the resulting sample bound, and compare how the bound changes with accuracy, confidence, and class size. I will distinguish this sufficient bound from the smallest sample size that might work in practice.

  6. Computational complexity and efficient learning

    I will distinguish the number of examples needed from the time needed to find and evaluate a suitable hypothesis. Using the finite-class example, I will examine the cost of searching for a consistent hypothesis and discuss the polynomial-time requirements of efficient PAC learning. This section will explain why a sample guarantee alone does not establish an efficient algorithm.

  7. Beyond finite classes: VC dimension Optional extension

    If time permits, I will introduce shattering and VC dimension as a way to describe the capacity of a hypothesis class without simply counting its elements. I will use thresholds on the real line as a simple example and explain how this motivates studying sample complexity for infinite hypothesis classes.

  8. Conclusion and references

    I will summarize what the PAC framework tells us about learning from finite data and revisit the distinction between statistical and computational requirements. I will collect references here and cite the sources used for definitions, theorem statements, and proofs throughout the completed website.
